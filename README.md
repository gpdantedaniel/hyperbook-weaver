# The Hyperbook Weaver 🕷️

The Hyperbook Weaver is a topic modeling pipeline designed to semantically link all the papers found in the [Hyperbook](https://bioengineering.hyperbook.mcgill.ca/), a website maintained by McGill University's [Bioengineering Department](https://www.mcgill.ca/bioengineering/) that hosts papers written by students from the course [BIEN 200](https://coursecatalogue.mcgill.ca/courses/bien-200/index.html). Using embeddings generated by LLMs, it links papers by clustering keywords together and finding common topics across papers.

## Installing the application

The application can be installed by simply cloning the repository to download all of its contents. 

```
git pull https://github.com/gpdantedaniel/hyperbook-weaver
```

## Setting up your AI infrastructure

The application depends on models to generate embeddings as well as text depending on your use case. This can be done three ways.

### Using Ollama 🦙

Ollama is an open-source platform that allows you to run models on your computer. You can download it [here](https://ollama.com/download). Once it's installed, you can pull any model of your choice from their [collection](https://ollama.com/search). For instance, pulling Qwen3-Embedding-0.6B looks like this

```sh
ollama pull dengcao/Qwen3-Embedding-0.6B:F16    # This is an example. You can always choose another model.
```

### Using HuggingFace Inference Endpoints 🤗

Hugging Inference Endpoints represent a solid choice when you lack the computational resources to run larger models. You can set up your own inference endpoint [here](https://huggingface.co/inference-endpoints/dedicated). Once that's done, you may add the endpoint's URL as well as its API key to your environment variables in the .env file.

```env
HF_TOKEN=your_huggingface_token
HF_ENDPOINT=your_huggingface_inference_endpoint
```

### Using Azure OpenAI

The application also supports OpenAI's embedding and generation models via Azure AI Foundry. You can set up your azure inference endpoints [here](https://azure.microsoft.com/en-us/products/ai-foundry). Once that's done, you can add your endpoint URL, its API version and its API key to your environment variables in the .env file.

```env
AZURE_OPENAI_API_KEY=your_azure_openai_api_key
AZURE_OPENAI_API_VERSION=your_azure_api_version_of_choice
AZURE_OPENAI_ENDPOINT=your_azure_openai_endpoint
```

## Running the application

### Using Docker 🐋

To run the application, you need [Docker](https://www.docker.com/) as well as [Python 3.12.0 or greater](https://www.python.org/downloads/). Once downloaded, access the cloned repository's root using the terminal to build and run the container using Docker.

``` sh
docker run build -t hyperbook-weaver .
docker run -p 7860 hyperbook-weaver
```

### Using Python 🐍

In addition, you can also initialize a local virtual environment in python:

```sh
python -m venv venv
venv/scripts/activate       # For Windows
source ./venv/bin/activate  # For Mac
```

And after accessing the /src directory

```sh
cd src
```

You can run the application manually

```sh
python app.py
```

Once this is done, you should be able to access your application at **localhost:7860** on your computer.
